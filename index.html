Project

Used Motorcycle Depreciation Analysis (SQL)

View on GitHub →
  • PostgreSQL
  • SQL
  • Data cleaning
  • Data analysis

I loaded a public Kaggle dataset of 1,061 used-motorcycle listings from India into PostgreSQL to answer one question: how fast does a used motorcycle lose its value? I measured value as the asking price divided by the bike’s new price (I call this “retention”), then wrote five queries to compare it by age, brand, number of owners, and mileage. 626 listings include the new price, so those are used for the retention numbers.

Key findings

  • Bikes keep about 97% of their new price after 1 year, 77% after 3 years, and 42% after 10 years. The biggest drop happens in the first few years.
  • Comparing bikes from 2015–2018, Royal Enfield holds value best at 84%. Most other brands are between 71% and 74%.
  • For the same model years, second-owner bikes keep 62% vs. 68% for first-owner bikes, about 6 points less.

How I did it

  1. Loaded the CSV into a PostgreSQL table using \copy.
  2. Created a clean listings table, pulled the brand out of each model name, and added a primary key and indexes.
  3. Calculated retention as selling_price / ex_showroom_price and age as 2020 - year.
  4. Wrote five queries using WHERE, GROUP BY, HAVING, CASE, and AVG. When comparing groups, I kept the model years the same so one group wasn’t just older.

Queries and results

Q1How much value does a bike keep at each age?GROUP BY, AVG 
SELECT
    2020 - year                                       AS age_years,
    COUNT(*)                                          AS listings,
    ROUND(AVG(selling_price / ex_showroom_price), 2)  AS avg_retention
FROM listings
WHERE ex_showroom_price IS NOT NULL
  AND year BETWEEN 2010 AND 2019
GROUP BY age_years
ORDER BY age_years;

Q3Does a second owner lower the price?WHERE … IN, GROUP BY 
SELECT
    owner_label,
    COUNT(*)                                          AS listings,
    ROUND(AVG(selling_price / ex_showroom_price), 2)  AS avg_retention
FROM listings
WHERE ex_showroom_price IS NOT NULL
  AND year BETWEEN 2014 AND 2017

Q4How does mileage relate to price?CASE, GROUP BY 
SELECT
    CASE
        WHEN km_driven < 10000 THEN '1. under 10k km'
        WHEN km_driven < 25000 THEN '2. 10k-25k km'
        WHEN km_driven < 50000 THEN '3. 25k-50k km'
        ELSE                        '4. 50k+ km'
    END                                               AS mileage,
    COUNT(*)                                          AS listings,
    ROUND(AVG(selling_price))                         AS avg_price_inr
FROM listings
GROUP BY mileage
ORDER BY mileage;

Data source

“Motorcycle Dataset” by Nehal Birla on Kaggle: kaggle.com/datasets/nehalbirla/motorcycle-dataset. I used the BIKE DETAILS.csv file (1,061 listings, prices in Indian rupees).

Limitations

  • Prices are asking prices, not final sale prices.
  • The new price is the model’s current price, not what the first owner paid, so older bikes are approximate.
  • Some groups are small (TVS has 10 bikes; there are 39 second-owner bikes in the owner comparison).
